fsspec_fuse.mount(url: str, mountpoint: str | PathLike[str], *, threads: int = 4, **storage_options) → Mount[source]¶

Mount url read-only at the existing directory mountpoint.

The URL resolves through the fsspec-rs registry shared by every extension in the process: native backends such as file://, s3://, db+sqlite://, or kafka:// when their packages are imported, and any Python fsspec backend otherwise. threads sets how many requests the mount serves at once.

class fsspec_fuse.Mount(url: str, mountpoint: str, session: RustMount)[source]¶

Bases: object

A read-only mount of an fsspec URL. Unmounts on unmount(), on context exit, or when garbage collected.

property mounted: bool¶

Whether the filesystem is still mounted. False after unmount() or an unmount from outside, such as fusermount3 -u.

unmount() → None[source]¶

Unmount and wait for the mount’s threads to stop. Calling it again does nothing.
